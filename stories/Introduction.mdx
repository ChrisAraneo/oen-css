# Oen CSS

A CSS framework built from [Bulma](https://bulma.io) 1.0.4, with five deliberate differences: every custom
property it declares is `--oen-*` instead of `--bulma-*`, and the six theme colors, the sans-serif stack,
the type scale, and the control metrics are its own.

Class names are untouched. `.button`, `.navbar`, `.columns`, `.is-primary`, and `.has-text-centered` behave
exactly as they do in Bulma, so markup is portable in both directions. What changes is the namespace of the
theme: the ~1 400 custom properties that carry the colors, fonts, radii, and spacing. Because those no
longer collide, a Bulma-themed region and an Oen-themed one can appear on the same page and be re-themed
independently. (The class rules are still the same selectors, so two stylesheets loaded together cascade in
load order. What is isolated is the theme, not the selectors.)

The palette is `#47b27b` primary, `#b24795` link, `#479db2` info, `#47b247` success, `#b26747` warning, and
`#b24747` danger. Bulma derives everything else from those six — the `-light`, `-dark`, `-invert`, and
`-on-scheme` variants, the lightness steps, and the dark-scheme values. See **Theme → Overview** for every
swatch.

The default stack is `"Trebuchet MS", Seravek, "Gill Sans Nova", "Segoe UI", Ubuntu, Calibri, "Noto Sans",
"DejaVu Sans", sans-serif`, carried by `--oen-family-primary` and `--oen-family-secondary`. The monospace
stack (`--oen-family-code`), the radii, the spacing, and the greys stay Bulma's defaults.

## Install

```sh
npm install @chris.araneo/oen-css
```

```html
<link rel="stylesheet" href="node_modules/@chris.araneo/oen-css/oen.min.css" />
```

Or, from a bundler:

```js
import '@chris.araneo/oen-css';
```

The package is CSS only. There is nothing to compile, no JavaScript runtime, and no peer dependency.

## Theming

The theme is a set of custom properties declared on `:root`, then re-declared under `[data-theme="dark"]`
and `.theme-dark`. Overriding one on any ancestor re-themes everything inside it:

```html
<div
  style="--oen-primary-h: 288deg; --oen-primary-s: 72%; --oen-primary-l: 56%"
>
  <button class="button is-primary">Purple</button>
</div>
```

Dark mode needs no JavaScript: `prefers-color-scheme` is honored, and the `data-theme` attribute
overrides it when you want an explicit choice. Use the theme switcher in the toolbar above to see
every story in both schemes.

See **Theme → Overview** for the palette, the live values of the key properties, and scoped overrides.

## How this gallery is organized

The sections mirror Bulma's own documentation, so anything you know from there is where you expect it:

- **Elements**: the single-purpose building blocks: buttons, tags, titles, tables, notifications, images.
- **Form**: inputs, selects, checkboxes, radios, file pickers, and the `field` / `control` layout system.
- **Components**: the composed pieces: card, navbar, modal, dropdown, menu, message, panel, tabs, pagination, breadcrumb.
- **Layout**: container, level, media object, hero, section, footer.
- **Grid**: the flexbox column system and both CSS-grid systems (smart and fixed).
- **Helpers**: color, spacing, typography, visibility, flexbox, and the remaining utilities.
- **Features**: skeleton loaders.

Every story is a plain HTML string styled only by the built `oen.css`. A few stories attach a few
lines of vanilla JavaScript where a component needs interaction (the dropdown, the modal, the navbar
burger, the tabs). That is the JavaScript a CSS-only framework leaves to you. Font Awesome is loaded in the
gallery so the icon examples render; it is not a dependency of the library.
